# Taller QR Bilingüe — Inventario La Granja

Proyecto interdisciplinario de Construcciones Metálicas e Inglés. Incluye fichas piloto con imágenes, vocabulario inglés, oraciones contextualizadas, audio y etiquetas QR.

Las etiquetas se instalan únicamente con autorización de los docentes de especialidad y sin interferir con el uso seguro de herramientas y equipos. Este repositorio público no debe incluir datos personales de estudiantes ni registros internos del inventario.
